# Блоки: написать один раз, показать везде

[English](blocks.md)

Модуль блоков (`alveby/atrium-blocks`) хранит небольшие куски текста или HTML в одном месте: телефон, который стоит в шапке, в подвале и на странице контактов, строка про доставку, плашка. Поменяли в **Блоках** — поменялось везде.

## Установка

```bash
composer require alveby/atrium-blocks
php artisan atrium:module:install alveby/atrium-blocks
```

## В админке

В **Блоках** одна запись на блок:

| Поле | Что это |
|---|---|
| Активность | Выключенный блок ничего не показывает, куда бы его ни поставили. |
| Название | Для редакторов: его видно в списке и в выборе редактора. |
| Код | Коротко, латиницей, уникален в пределах сайта (`phone`). По нему блок просит шаблон. |
| Содержимое | Текст с теми же тремя режимами, что и любой текст: простой, HTML, визуальный редактор. Пишется на каждом языке содержимого; для языка без текста показывается текст языка по умолчанию. |

Блок принадлежит сайту: у каждого сайта свой `phone`.

## В тексте

В любом визуальном редакторе нажмите **+**, выберите **Блок**, найдите блок по названию. В редакторе появится плашка `Блок: Телефон`, а сайт нарисует блок на её месте ([как работают вставки](embeds.ru.md)). В метке лежит id блока, поэтому смена кода потом ничего не ломает. Внутри блока может быть форма или другой блок.

## В шаблоне

```blade
<a href="tel:+100">@block('phone')</a>
```

а в PHP и в шаблоне, который печатает сырой HTML:

```blade
{!! atrium_block('phone') !!}
```

Блок — это текст как он написан: HTML выводится как HTML, поэтому давайте этот модуль только тем, кому можно писать HTML. Если на сайте нет такого блока, он выключен или модуль не установлен, место остаётся пустым. Берётся язык сайта; блок другого сайта не показывается никогда.

## Скорость

Блок читается один раз на сайт, язык и код и час лежит в кеше; сохранение или удаление любого блока заставляет следующую страницу прочитать заново, на любом хранилище кеша. Правка в обход модели (прямой SQL) дождётся конца часа или `php artisan cache:clear`. Форма или блок внутри блока подставляются на каждом запросе, уже после кеша.

## Блок, который содержит сам себя

Блок, который содержит сам себя, напрямую или через другие блоки, обрывается там, где повторился: `A` с `B` внутри и `A` внутри `B` покажет текст `A`, текст `B` и дальше ничего.

## Файлы

Подписи на английском и русском написаны вручную, остальные 13 языков — машинный перевод; чтобы поменять слово, переопределите `atrium-blocks::blocks` у себя в `lang/vendor/atrium-blocks` (`php artisan vendor:publish --tag=atrium-blocks-lang`).
