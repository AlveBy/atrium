# Меню

[English](menus.md)

Модуль меню (`alveby/atrium-menus`) даёт редакторам собирать меню сайта в админке: шапку, подвал и любое другое, которое попросит тема. Каждое меню принадлежит сайту и одному языку (или всем сразу), а его пункты образуют дерево, которое правят перетаскиванием.

## Установка

```bash
composer require alveby/atrium-menus
php artisan atrium:module:install alveby/atrium-menus
```

С `--demo` появятся меню шапки и подвала на языке установки (`APP_LOCALE`, любой из 15 языков панели; неизвестный — английский) и отдельные меню для английского, немецкого и русского, собранные из установленных модулей: каталог раскрывает свои разделы, новости, магазины и FAQ получают по пункту.

## В админке

В разделе **Меню** одна запись на одно меню:

| Поле | Что это |
|---|---|
| Название | Только для редакторов |
| Код | По нему меню просит тема: `header`, `footer`. Латиница, цифры, `-` и `_` |
| Язык | Один язык контента или «Все языки». Меню на языке посетителя главнее меню для всех языков |
| Пункты | Дерево |

Код уникален в пределах сайта и языка: один и тот же `header` может быть один раз для всех языков и ещё раз для немецкого.

У каждого пункта есть:

- **Заголовок**.
- **Ссылка**: без ссылки (заголовок, который только раскрывает вложенные пункты), адрес (`/contacts`, `https://…`, `mailto:…`) или запись любого модуля со страницами, выбранная по названию. Ссылка на запись следует за записью: смените ей код или перенесите в другой раздел, и меню поведёт на новый адрес; удалите или выключите её, и пункт пропадёт.
- **Открывать**: в том же окне или в новом.
- **Иконка**: CSS-классы, например `icon icon-phone`.
- **Активность**: выключенный пункт прячется вместе с вложенными.
- **Раскрыть под пунктом** и **Сколько уровней раскрыть**: записи модуля, выведенные под пунктом. Модуль-дерево (разделы каталога) раскрывает своё дерево до пяти уровней от корня или от записи, на которую ведёт пункт; плоский модуль выводит список записей. Только активные записи текущего сайта, по сортировке.

Пункты перетаскивают за ручку: над другим пунктом, под ним или на него, чтобы стать вложенным. Кнопки рядом с пунктом делают то же с клавиатуры (выше, ниже, вложить, вынуть). В меню до 500 пунктов, до четырёх уровней.

## На сайте

С темой (`alveby/atrium-theme`) модуль рисует меню в шапке из меню с кодом `header` и добавляет меню `footer` над строкой копирайта. Пока на сайте нет меню `header`, тема показывает своё меню модулей.

В любом другом месте:

```blade
<x-atrium-menu code="header" />
<x-atrium-menu code="footer" class="footer-menu" label="Site map" />
<x-atrium-menu code="header" language="de" />
```

Компонент выводит `<nav>` с вложенными `<ul>`. Ссылка на текущую страницу получает `aria-current="page"`, её пункт и все пункты выше — класс `is-active`, пункт с вложенными — `has-children`. Если у сайта нет активного меню с таким кодом, ничего не выводится.

Чтобы нарисовать меню по-своему, возьмите дерево:

```php
$menu = atrium_menu('header');   // или atrium_menu('header', 'de')

// ['code' => 'header', 'name' => 'Header', 'items' => [
//     ['title' => 'Shop', 'url' => 'https://example.com/shop', 'target' => null,
//      'icon' => null, 'current' => false, 'active' => true, 'children' => [...]],
// ]]
```

`null` значит, что такого меню нет.

Чтобы оставить шапку или подвал темы, задайте их в `config/atrium-theme.php`; модуль заполняет только ключи, равные `null`:

```php
'header_menu' => 'atrium-theme::partials.menu',
'footer_menu' => 'partials.footer',
```

## Кеш

Готовое меню кешируется по сайту, языку и коду. Сохранение меню или любой записи с публичными страницами начинает кеш заново, поэтому раскрытые под пунктом записи и ссылки на записи сразу актуальны. Теги кеша не нужны, подходит любое хранилище.

## API и MCP

Меню — модуль API админки, поэтому токен с `menus:read` и `menus:write` читает и пишет их по адресу `/api/v1/menus` вместе с деревом:

```bash
curl -H "Authorization: Bearer <token>" https://example.com/api/v1/menus/1
```

```json
{"data": {"id": 1, "code": "header", "name": "Header", "language": null, "tree": [
    {"id": 3, "title": "Shop", "link": {"type": "url", "url": "/shop"}, "target": null,
     "icon": null, "active": true, "source": null, "source_depth": 1, "children": []}
]}}
```

`PUT` с `tree` заменяет пункты: пункты со своим `id` обновляются, новые создаются, пропавшие удаляются. Ссылка на запись — `{"type": "record", "model": "Atrium\\Catalog\\Models\\Product", "id": 5}`. MCP-инструменты (`list_records`, `get_record`, `update_record`) работают так же.
