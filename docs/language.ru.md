# Формулы: свой язык Atrium

[English](language.md)

`alveby/atrium-language` — первая часть [единого языка](extensions.ru.md#уровень-2-один-язык-формулы-правила-и-плагины) Atrium: формулы, которые пишут как в таблице, дерево с типами, в которое они разбираются, проверка до запуска и интерпретатор с лимитами. Он даёт условия («показать этот блок, если …»), калькуляторы и вычисляемые значения всему, что его вызовет.

Формула читает только те поля, которые ей дали, вызывает только зарегистрированные функции, не превращается в PHP и не может занять страницу навсегда.

Чего здесь пока нет: текстового синтаксиса плагинов, компиляторов в PHP и JavaScript, редактора формул в админке и хранения версий формул.

## Установка

```bash
composer require alveby/atrium-language
```

Это библиотека, а не модуль: ни таблиц, ни пункта меню, включать нечего.

## Из PHP

```php
use Atrium\Language\Context;
use Atrium\Language\Formula;
use Atrium\Language\FormulaError;
use Atrium\Language\Schema;

// Поля, которые формула может назвать: ключ, тип и любые другие имена.
$schema = Schema::make()
    ->number('quantity', 'Quantity', 'Количество')
    ->number('price', 'Price', 'Цена')
    ->date('shipped', 'Shipping date', 'Дата отгрузки')
    ->records('lines', Schema::make()->number('amount', 'Amount', 'Сумма'), 'Lines', 'Строки');

// Их значения по ключам.
$context = Context::make($schema, [
    'quantity' => 3,
    'price' => '19.90',
    'shipped' => '2026-12-01',
    'lines' => [['amount' => 10], ['amount' => 15.5]],
]);

$formula = Formula::parse('Количество * Цена + СУММ(Строки.Сумма)');

$formula->check($context)->passes();        // true
$result = $formula->evaluate($context);

(string) $result->value;                    // '85.2'
array_keys($result->fields);                // ['quantity', 'price', 'lines']
```

| Вызов | Что даёт |
|---|---|
| `Formula::parse($text)` | Формулу или `FormulaError` со строкой и позицией того, что не читается. |
| `Formula::fromJson($json)`, `$formula->toJson()` | Формулу в виде [хранимого JSON](#дерево). |
| `Formula::fromNode($node)`, `$formula->root` | Формулу, собранную из узлов, и её дерево. |
| `$formula->check($context)` | `Check`: `passes()`, `problems` (все сразу), `messages($locale)`, тип результата `type`. |
| `$formula->evaluate($context)` | `Result`: `value` и `fields` — прочитанные поля с использованными значениями. Сначала проверяет. |
| `$formula->explain($context)` | То же и ещё `trace`: как получилось значение. |

### Контекст

`Context::make($schema, $values)` принимает значения массивом или `ArrayAccess` по ключам полей; отсутствующее значение пустое. Каждый метод возвращает изменённую копию:

| Метод | Что задаёт |
|---|---|
| `allow('deals.view', …)` | Права автора формулы, которые могут требовать [функции](#добавить-функцию). |
| `withLimits(new Limits(…))` | Другие [лимиты](#лимиты). |
| `withToday($date)` | День, который даёт `СЕГОДНЯ()`, вместо сегодняшнего в часовом поясе приложения. |
| `withFunctions($functions)` | Другой реестр функций вместо реестра приложения. |
| `withClock($nanoseconds)` | Другие часы для лимита времени, для тестов. |

Значение приводится к типу поля, когда формула читает его впервые:

| Тип поля | Какие значения PHP принимает | В результате |
|---|---|---|
| число | `int`, `float`, текст вида `-12.5`, `Brick\Math\BigDecimal` | `BigDecimal` |
| текст | `string`, `Stringable` | `string` |
| да или нет | `bool` | `bool` |
| дата | `DateTimeInterface`, текст `2026-11-28` | `Atrium\Language\Values\Date` |
| записи | любой перебираемый набор массивов или `ArrayAccess` по ключам полей записей | список; одна запись — `Values\Record` |

Пустое значение — это `null`. Пустой текст в поле числа, даты или «да или нет» тоже пустой: так его присылает форма.

**Что формула может видеть, решает схема.** Кладите в неё только те поля, которые может читать автор формулы: другие она назвать не сможет.

### Как посчитано

`explain()` сохраняет `Step` для каждой посчитанной части: узел, его значение и шаги, из которых он сложился. Ветки `ЕСЛИ`, по которой не пошли, и операндов после того, который решил `И` или `ИЛИ`, там нет.

```php
$step = Formula::parse('Quantity * Price')->explain($context)->trace;

(string) $step->value;               // '59.7'
(string) $step->steps[1]->value;     // '19.9'
$step->steps[1]->node->name;         // 'Price'
```

## Как писать формулу

### Значения

| Вид | Как пишется |
|---|---|
| Число | `12`, `0.5`. Дробная часть отделяется точкой: запятая разделяет аргументы. |
| Текст | `"Готово"`; кавычка внутри удваивается: `"сорт ""экстра"""`. |
| Дата | `28.11.2026` или `#2026-11-28#`. |
| Да или нет | `ИСТИНА`, `ЛОЖЬ`, `TRUE`, `FALSE` в любом регистре. |

### Имена полей

Поля называют по имени, а не по адресу ячейки. Имя может быть русским или английским, содержать пробелы и кончаться числом: `Цена`, `Дата отгрузки`, `Этап 2`. Несколько пробелов считаются одним, регистр не важен.

Любое другое имя берётся в квадратные скобки: `[Цена (без НДС)]`, `[Стоимость, $]`; закрывающая скобка внутри удваивается: `[a]]b]` — это `a]b`.

Поле связанных записей пишется через точку: `Строки.Сумма` — список сумм всех строк, который можно сложить функцией вроде `СУММ`.

### Операторы

От самых слабых к самым сильным:

| Операторы | Что делают |
|---|---|
| `ИЛИ` `OR` | Верно хотя бы одно. |
| `И` `AND` | Верны оба. |
| `НЕ` `NOT` | Обратное. |
| `=` `<>` `<` `<=` `>` `>=` | Сравнение. Только одно за раз: пишите `И(1 < x; x < 10)`, а не `1 < x < 10`. |
| `&` | Склеивает тексты, числа, даты и «да или нет» в один текст; дата читается как `2026-11-28`, «да или нет» — как `TRUE` или `FALSE`. |
| `+` `-` | Сумма и разность; дата плюс или минус целые дни; дата минус дата — число дней. |
| `*` `/` | Произведение и частное. |
| `^` | Степень с целым показателем от -1000 до 1000. |
| `%` | Сотая доля: `15%` — это `0.15`. |
| `-` перед значением | Минус. Как в Excel, `-2^2` равно `4`. |
| `.` | Поле связанной записи. |

Слова `И`, `ИЛИ`, `НЕ`, `AND`, `OR`, `NOT` считаются операторами только **заглавными буквами**, чтобы они могли быть частью имени: `Условия и сроки` — одно поле. Записанные как функции, `И(…)`, `or(…)`, `Не(…)`, они работают в любом регистре.

Порядок меняют скобки. Аргументы разделяются `;` или `,`.

### Условия

`ЕСЛИ(условие; тогда; иначе)` или `IF`. Считается только та ветка, по которой пошли. Без третьего аргумента при ложном условии результат пустой. Обе ветки должны давать один тип.

`И` и `ИЛИ` останавливаются на операнде, который решил ответ.

## Значения и пустые значения

- **Числа — точные десятичные**: `0.1 + 0.2` равно `0.3`. После точки хранится 20 знаков с округлением половины от нуля, перед точкой — 40 цифр.
- **Даты** — дни календаря с 1 по 9999 год, без времени.
- **Тексты сравниваются без учёта регистра**: `"Готово" = "готово"` верно.
- **Сравниваются только значения одного типа.** `<`, `>` и подобные упорядочивают числа, тексты и даты.

Пустое значение не превращается молча в ноль:

| Где | Чем считается пустое значение |
|---|---|
| Ждут текст, или это `&` | Пустым текстом. |
| Нужно число, дата или «да или нет» | Ошибкой, в которой названо поле. |
| `=` и `<>` | Равно только другому пустому значению или `""`. |
| `СУММ`, `СРЗНАЧ`, `МИН`, `МАКС`, `СЧЁТ` | Пропускается. |
| `ЕПУСТО`, `ЕСЛИПУСТО` | Для этого они и есть: `ЕСЛИПУСТО(Скидка; 0)`. |

## Функции

У каждой функции есть русское и английское имя, и любое пишется в любом регистре. `ЕСЛИ`, `И`, `ИЛИ` и `НЕ` — часть самого языка.

### Числа

| Функция | Английское имя | Результат |
|---|---|---|
| `СУММ(значения…)` | `SUM` | Сумма чисел и списков чисел; 0, если их нет. |
| `СРЗНАЧ(значения…)` | `AVERAGE` | Среднее; ошибка, если значений нет. |
| `МИН(значения…)`, `МАКС(значения…)` | `MIN`, `MAX` | Наименьшее и наибольшее; ошибка, если значений нет. |
| `СЧЁТ(значения…)`, `СЧЕТ` | `COUNT` | Сколько значений не пустые — любого типа или связанных записей. |
| `ОКРУГЛ(число; знаки)` | `ROUND` | Округление половины от нуля; знаков от -40 до 20. |
| `ОКРУГЛВВЕРХ(число; знаки)` | `ROUNDUP` | Округление от нуля. |
| `ОКРУГЛВНИЗ(число; знаки)` | `ROUNDDOWN` | Округление к нулю. |
| `ЦЕЛОЕ(число)` | `INT` | Ближайшее целое снизу. |
| `ABS(число)` | `ABS` | Без знака. |
| `ОСТАТ(число; делитель)` | `MOD` | Остаток со знаком делителя. |
| `КОРЕНЬ(число)` | `SQRT` | Квадратный корень. |

### Тексты

| Функция | Английское имя | Результат |
|---|---|---|
| `ДЛСТР(текст)` | `LEN` | Число символов. |
| `ЛЕВСИМВ(текст; [сколько])`, `ПРАВСИМВ(текст; [сколько])` | `LEFT`, `RIGHT` | Первые или последние символы; по умолчанию один. |
| `ПСТР(текст; начало; сколько)` | `MID` | Часть текста, счёт с 1. |
| `ПРОПИСН(текст)`, `СТРОЧН(текст)` | `UPPER`, `LOWER` | Заглавными или строчными буквами. |
| `СЖПРОБЕЛЫ(текст)` | `TRIM` | Без пробелов по краям и с одним между словами. |
| `СЦЕПИТЬ(значения…)`, `СЦЕП` | `CONCAT` | Значения и списки значений, склеенные подряд. |
| `ПОДСТАВИТЬ(текст; что; чем)` | `SUBSTITUTE` | Заменено каждое вхождение; регистр важен. |
| `ПОВТОР(текст; раз)` | `REPT` | Текст, повторённый несколько раз. |
| `СОДЕРЖИТ(текст; часть)` | `CONTAINS` | Есть ли часть в тексте, без учёта регистра. |

Искомый текст в `ПОДСТАВИТЬ` и `СОДЕРЖИТ` — не длиннее 255 символов.

### Пустые значения

| Функция | Английское имя | Результат |
|---|---|---|
| `ЕПУСТО(значение)` | `ISBLANK` | Пустое ли значение или пустой текст. |
| `ЕСЛИПУСТО(значение; вместо)` | `IFBLANK` | Значение, а если оно пустое — `вместо`. |

### Даты

| Функция | Английское имя | Результат |
|---|---|---|
| `СЕГОДНЯ()` | `TODAY` | Сегодняшний день. |
| `ДАТА(год; месяц; день)` | `DATE` | День; 13-й месяц — это январь следующего года, как в Excel. Год берётся как написан. |
| `ГОД(дата)`, `МЕСЯЦ(дата)`, `ДЕНЬ(дата)` | `YEAR`, `MONTH`, `DAY` | Часть даты. |
| `ДАТАМЕС(дата; месяцы)` | `EDATE` | Тот же день через несколько месяцев или последний день более короткого месяца. |
| `КОНМЕСЯЦА(дата; месяцы)` | `EOMONTH` | Последний день месяца через несколько месяцев. |
| `ДНИ(конец; начало)` | `DAYS` | Сколько дней от `начало` до `конец`. |
| `ДЕНЬНЕД(дата; [тип])` | `WEEKDAY` | День недели: тип 1 (по умолчанию) считает с воскресенья, тип 2 — с понедельника. |

## Ошибки

Никаких `#ЗНАЧ!`. Проблема говорит, что не так и где, на 15 языках админки:

```php
try {
    Formula::parse('Quantity * Price')->evaluate(Context::make($schema, ['quantity' => 3]));
} catch (FormulaError $error) {
    $error->problem()->code;            // 'value.empty_field'
    $error->problem()->at->column;      // 12
    $error->problem()->message('ru');   // Строка 1, позиция 12: Поле «Price» пустое, а формуле нужно значение типа «число».
    $error->getMessage();               // то же на языке приложения
}
```

`check()` находит всё, что можно узнать до запуска, и сразу всё (первые 100 проблем): неизвестные поля и функции, неподходящие типы, число аргументов, права, глубину вложенности и списки, вложенные друг в друга глубже 8 уровней. То, что зависит от значений (пустое поле, деление на ноль, лимит), останавливает запуск. Любой отказ формулы — это `FormulaError`.

## Лимиты

| `Limits` | По умолчанию | Что считается |
|---|---|---|
| `steps` | 200 000 | Посчитанные части формулы и пройденные элементы списков. |
| `milliseconds` | 1 000 | Время; проверяется перед каждым шагом. |
| `memory` | 2 097 152 | Байты созданных значений в сумме за запуск: 16 на каждое значение, пустые тоже, плюс байты текста. Список, положенный в много мест — в каждый результат цикла, в объяснение, — считается в каждом. |
| `depth` | 64 | Насколько глубоким может быть дерево. |
| `recursion` | 8 | Сколько запусков может быть открыто друг в друге. |

Запуск, начатый изнутри функции другого запуска, тратит тот же запас под внешними лимитами: вызывая формулы из формул, свежих лимитов не получить.

Часть границ поднять нельзя: текст формулы — не длиннее 10 000 символов и не глубже 64 скобок; в дереве не больше 5 000 узлов и 200 уровней; хранимая формула — не больше 1 000 000 байт; списки и записи, переданные как значения, вкладываются друг в друга не глубже 64 уровней; числа ограничены, как сказано выше.

PHP нельзя остановить посреди функции: время и шаги проверяются между частями формулы. Функция, которая крутит цикл или создаёт что-то большое, спрашивает об этом сама (ниже).

## Добавить функцию

Функция объявляет свои имена, что принимает, что отдаёт, какое право ей нужно и PHP, который это делает. С установленной Atrium модуль регистрирует её как любое другое [расширение](extensions.ru.md):

```php
use Atrium\Admin\Facades\Hook;
use Atrium\Language\Functions\FormulaFunction;
use Atrium\Language\Functions\Functions;
use Atrium\Language\Functions\Invocation;
use Atrium\Language\Functions\Parameter;
use Atrium\Language\Types\Type;

Hook::register(Functions::REGISTRY, 'shop.vat', new FormulaFunction(
    names: ['VAT', 'НДС'],
    parameters: [Parameter::of(Type::number()), Parameter::of(Type::number())->optional()],
    returns: Type::number(),
    handler: fn (Invocation $call) => $call->argument(0)->multipliedBy($call->whole(1, 0, 100, 20))->withPointMovedLeft(2),
    permission: 'shop.view',
));
```

Без Atrium функцию добавляют в реестр: `Functions::standard()->add($function)` — и передают его в `withFunctions()`.

- **Параметры.** `Parameter::of($type)`, затем `optional()` (можно не указывать, как и все после него), `variadic()` (последний, сколько угодно) и `orEmpty()` (принимает пустое значение; иначе запуск останавливается и называет, что пусто).
- **Типы.** `Type::number()`, `text()`, `boolean()`, `date()`, `listOf($type)`, `record($schema)`, `any()` и `oneOf(…)` для параметра, который принимает один из нескольких.
- **Тип результата** — один тип или `any`, не `oneOf`; это может быть замыкание от типов аргументов. Обработчик возвращает обычное значение PHP этого типа; оно проверяется и учитывается в лимите памяти.
- **Обработчик** получает один `Invocation`: `argument($i)`, `text($i)`, `whole($i, $min, $max, $default)`, `values()` (все аргументы, списки раскрыты, пустые пропущены), `today`, `fail($code, $params)`.
- **Лимиты.** Вызывайте `$call->step()` на каждом обороте своего цикла и `$call->mustFit($bytes)` перед созданием большого значения.
- **Права.** Если задан `permission`, формула, в контексте которой нет `allow()` на это право, не пройдёт проверку.
- **Имена** — буквы, цифры и `_`. Функции самого языка идут первыми: модуль не может изменить, что делает `SUM`.

Функция — это PHP доверенного пакета: за то, что она читает и пишет, отвечает он сам.

## Дерево

Формула — это дерево типизированных узлов, внутреннее представление, которое будут строить и правила из блоков, и плагины, написанные текстом. У него есть версия, как у контракта.

| Узел | Класс в `Atrium\Language\Ir` | Ключи JSON |
|---|---|---|
| Значение | `Literal` | `type`: `empty`, `boolean`, `text`, `number` или `date`; `value` |
| Поле | `Field` | `name` |
| Элемент цикла | `Variable` | `name` |
| Поле связанной записи | `Member` | `of`, `name` |
| Оператор | `Operation` | `operator`, `operands` |
| Вызов функции | `Call` | `function`, `arguments` |
| Условие | `Condition` | `when`, `then`, `otherwise` (можно не указывать) |
| Цикл по списку | `Each` | `source`, `variable`, `body`, `where` (можно не указывать) |

Операторы: `add`, `subtract`, `multiply`, `divide`, `power`, `negate`, `percent`, `concat`, `equal`, `not_equal`, `less`, `less_or_equal`, `greater`, `greater_or_equal`, `and`, `or`, `not`. У `negate`, `percent` и `not` один операнд; у `add`, `multiply`, `concat`, `and` и `or` — один и больше; у остальных два.

Любой узел может нести `at` — строку и позицию, откуда он взят. `Quantity * 2`:

```json
{
    "version": 1,
    "root": {
        "node": "operation",
        "operator": "multiply",
        "operands": [
            {"node": "field", "name": "Quantity", "at": [1, 1]},
            {"node": "literal", "type": "number", "value": "2", "at": [1, 12]}
        ],
        "at": [1, 10]
    }
}
```

Числа в JSON записаны текстом, чтобы не терять точность; даты — `YYYY-MM-DD`.

`Each` пока нельзя записать формулой. Как узел он работает: `body` для каждого элемента `source`, для которого `where` истинно, сам элемент — это `Variable`; результат — список.

Хранимому JSON не доверяют. До разбора каждый ключ в нём должен быть из формата и записан обычными буквами (без кодов `\u`), а массивов и объектов он открывает не больше 20 000. Потом он читается узел за узлом с ограничениями по глубине и числу и проходит ту же проверку, что и текст.

## Чего формула не может

- Читать что-либо, кроме полей своей схемы.
- Вызывать что-либо, кроме функций реестра, разрешённых её контекстом.
- Стать PHP: ничего не выполняется через `eval`, не подключается и не компилируется, а имена никогда не используются как имена PHP.
- Добраться до файлов, базы данных, сети или глобальных переменных PHP.
- Работать без конца или бесконечно растить значение: см. [лимиты](#лимиты).
