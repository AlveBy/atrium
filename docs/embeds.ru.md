# Вставки: форма или блок внутри текста

[English](embeds.md)

Вставка — это то, что редактор кладёт в текст страницы, а сайт рисует на её месте: сегодня это форма обратной связи, а когда появятся модули — блок с телефоном или список товаров. В тексте лежит только метка, поэтому посетитель всегда видит актуальную форму или блок, даже если сама страница закеширована.

## Что делает редактор

В каждом визуальном редакторе (содержимое страницы, текст новости, описание товара, повторяемый текст) в панели есть кнопка **+** «Вставить форму или блок».

1. Поставьте курсор туда, где должна быть вставка.
2. Нажмите кнопку и выберите тип: **Форма**, позже **Блок** и другие. Предлагаются только типы установленных модулей и только те, которые этому редактору можно видеть.
3. Введите часть названия, чтобы сузить список, и нажмите на нужный пункт.

В тексте появится подписанная плашка, например `Форма: Свяжитесь с нами`. Её можно переносить, копировать и удалять, как картинку; клавиша Delete убирает её. Сохраните форму как обычно. Если форму или блок потом выключат или удалят, на странице на их месте просто ничего не будет: ни ошибки, ни пустой рамки.

В режиме **HTML** поля то же самое — одна строка, и набрать её руками тоже можно:

```html
<div data-atrium-embed="form" data-id="3"></div>
```

## Что делает сайт

Тема выводит все тексты страницы, раздела, товара и так далее через директиву Blade `@embeds`, которая при каждом запросе подменяет метки на HTML элемента. В собственном шаблоне — так же:

```blade
@embeds($page->detail_text)
```

вместо `{!! $page->detail_text !!}`. Текст без меток директива не трогает (один поиск по строке), принимает строку, `null` или `Htmlable`, а неустановленный тип, id, который ни на что не указывает, и вставка, упавшая с ошибкой, дают пустую строку; ошибка попадает в журнал, остальная страница рисуется.

## Свой тип вставки

Модуль добавляет тип один раз, при загрузке:

```php
use Atrium\Admin\Embeds\Embeds;
use Atrium\Admin\Hooks\Hooks;

$this->app->make(Hooks::class)->register(Embeds::REGISTRY, 'banner', new BannerEmbed);
```

Ключ (`banner`) попадает в метку, поэтому не меняйте его. `BannerEmbed` реализует `Atrium\Admin\Embeds\Embed`:

| Метод | Что делает |
|---|---|
| `label()` | Название в списке **Вставить**, на языке админки. |
| `available()` | `false`, если модуль за этим типом не установлен: тип тогда не предлагается и не рисуется. |
| `permitted(?AdminUser)` | Может ли этот администратор выбирать элементы типа. Иначе выбор отвечает 403. |
| `options(string $search)` | Элементы по набранным словам, вида `[['id' => '3', 'label' => 'Свяжитесь с нами']]`. Ограничьте их число: у выбора нет страниц. |
| `labels(array $ids)` | Названия элементов по id, для плашки в редакторе. |
| `render(string $id)` | HTML на сайте. Id, который ни на что не указывает, или выключенный элемент дают `''`. |

Для записи модели Eloquent унаследуйте `Atrium\Admin\Embeds\ModelEmbed` и напишите два метода: модель и вид одной записи на сайте. Список, поиск, право (`view` модуля), проверка «установлен ли модуль» и пустой ответ для пропавшей записи уже внутри. Вся вставка форм выглядит так:

```php
final class FormEmbed extends ModelEmbed
{
    public function label(): string
    {
        return __('atrium-forms::forms.fields.form');
    }

    protected function model(): string
    {
        return Form::class;
    }

    protected function renderRecord(Model $record): string
    {
        return FormComponent::inline((string) $record->getAttribute('code'), ['ajax' => true]);
    }
}
```

Выбор отдаётся по адресу `GET /admin/embeds/{type}?q=…` (и `?ids=1,2` за названиями), а список типов — это Inertia-свойство `embeds`, поэтому своих маршрутов и JavaScript модулю не нужно.

## Что ещё полезно знать

- Метка — обычный HTML, поэтому она переживает экспорт, импорт, API и перенос из Битрикса или WordPress, как любой другой текст. Редактор хранит её как `<div data-atrium-embed="form" data-id="3"></div>`; запись с одинарными кавычками или другим регистром тоже читается.
- Тексты кешируются вместе с меткой, а не с формой: у формы всегда свежие токены CSRF и защиты от спама.
- `Embeds::render()` — единая точка входа; вызывайте её из PHP, когда собираете HTML сами.
