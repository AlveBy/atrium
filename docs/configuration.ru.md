# Настройка Atrium

[English](configuration.md) · [Русский](configuration.ru.md)

Почти всё, что меняет владелец сайта, делается в самой админке: сайты и их домены, языки контента, счётчики и коды подтверждения, `robots.txt`, администраторы и роли. Эта страница — про то, что задаётся в файлах: `.env` и `config/atrium.php` (его публикует `atrium:install`).

После правки на боевом сайте снова выполните `php artisan config:cache`.

## Основные настройки

| Настройка | Где | По умолчанию | Что делает |
|---|---|---|---|
| `prefix` | конфиг | `admin` | Адрес админки: `/admin` |
| `resources` | конфиг | `[]` | Модули: модели Eloquent, реализующие `Administrable`. См. [Свой модуль](modules.ru.md) |
| `menu` | конфиг | рабочий стол, администраторы, роли, сайты, языки, API-токены | Постоянные пункты меню; модули, которых здесь нет, добавляются после первого пункта. Подпись может быть ключом перевода |
| `ATRIUM_NAME`, `ATRIUM_LOGO`, `ATRIUM_FAVICON` | .env | `Atrium` | Название и картинки в шапке и на вкладке админки |
| `ATRIUM_LOCALE` | .env | `en` | Язык админки для гостей, чей язык браузера не в `locales`; каждый администратор выбирает свой в шапке |
| `locales` | конфиг | 15 языков | Языки админки; уберите строку, и язык пропадёт из переключателя |
| `pagination` | конфиг | 20 на страницу | Размеры страниц списков |
| `ATRIUM_DEMO` | .env | `false` | Демо-магазин. Выключенный, он уходит из меню и с сайта; таблицы остаются |
| `ATRIUM_TIMINGS` | .env | `true` | Замер времени ответа публичных страниц для двух плиток скорости на рабочем столе. `ATRIUM_TIMINGS_SAMPLE_RATE=0.1` — замерять каждую десятую |

Любую строку интерфейса админки можно переписать:

```bash
php artisan vendor:publish --tag=atrium-lang
```

Файлы окажутся в `lang/vendor/atrium/{язык}/`; поправьте нужные строки, остальное удалите.

## Почта и код входа

После пароля админка спрашивает код, отправленный на почту администратора. Пароль живёт, пока его не сменят, а код действует минуты, так что одного утёкшего пароля мало.

Настройте почту до первого входа — обычными переменными Laravel `MAIL_*` (см. [Установка](installation.ru.md#свой-сервер)). Проверить, не входя в админку:

```bash
php artisan tinker --execute="Mail::raw('test', fn (\$m) => \$m->to('you@example.com')->subject('test'))"
```

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `ATRIUM_2FA_ENABLED` | `true` | Код входа. Выключайте, только если почты нет совсем |
| `ATRIUM_2FA_TTL` | `10` | Сколько минут действует код |
| `ATRIUM_2FA_RESEND_AFTER` | `60` | Через сколько секунд можно запросить новый |

С `MAIL_MAILER=log` (локальная машина) код пишется в конец `storage/logs/laravel.log`.

Почта сломалась, и войти нельзя? Поставьте `ATRIUM_2FA_ENABLED=false`, выполните `php artisan config:cache`, войдите, почините почту и включите код обратно.

Забытый пароль меняет суперадмин в разделе «Администраторы». Если вы единственный, заведите из консоли ещё одного суперадмина и смените пароль им:

```bash
php artisan atrium:user --superadmin
```

## Файлы и картинки

Файлы, загруженные в админке, ложатся на диск `public` (`storage/app/public`) и отдаются через ссылку `public/storage`, которую делает `atrium:install`.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `uploads.directory` | `uploads` | Папка внутри диска |
| `uploads.max_size` | `5120` | Самый большой файл, КБ |
| `uploads.image_max_size` | `2048` | Самая большая картинка, КБ |
| `uploads.allowed_extensions` | jpg, jpeg, png, gif, webp, pdf, doc, docx, xls, xlsx | Что можно загружать |
| `ATRIUM_UPLOADS_WEBP` | `true` | Класть рядом с загруженным JPEG или PNG облегчённую копию в WebP |

Копия называется по оригиналу, `photo.jpg.webp`, и веб-сервер отдаёт её браузерам, которые понимают WebP, по адресу оригинала: ни в базе, ни в шаблонах ничего не меняется. Apache делает это правилом в `public/.htaccess`, nginx — правилом из раздела [Установка](installation.ru.md#веб-сервер). Без такого правила копии лучше выключить: они займут место и до посетителей не дойдут. Копиям нужен GD с поддержкой WebP; без него файл просто загрузится без копии.

Сначала срабатывают лимиты PHP: файл больше `upload_max_filesize` или `post_max_size` из `php.ini` до Atrium не дойдёт.

## API-токены

Каждый модуль доступен и по HTTP API на `/api/v1` — для программ и интеграций. API сам себя описывает: `/api/v1` отвечает документацией в Markdown по всем модулям и их полям, `/api/v1/openapi.json` — схемой OpenAPI.

Токен выдаётся в админке, в разделе «API-токены»: выберите модули и для каждого — чтение или запись, по желанию срок действия. Токен показывается один раз. Он передаётся заголовком:

```bash
curl -H "Authorization: Bearer <token>" https://example.com/api/v1/articles
```

Токен никогда не может больше, чем его владелец сейчас: если у администратора отняли право править статьи, его токены его тоже теряют. Самих администраторов в API нет (`api.except`).

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `api.prefix` | `api/v1` | Адрес API |
| `api.except` | `['users']` | Ключи модулей, которых никогда нет в API |

## ИИ-ассистенты (MCP)

ИИ-ассистент, который умеет MCP (Claude, ChatGPT, Cursor и другие), подключается к `/mcp` с API-токеном и читает и правит модули за вас: «добавь три новости», «подними цены в разделе на 5%». У него семь инструментов: `list_modules`, `describe_module`, `list_records`, `get_record`, `create_record`, `update_record`, `delete_record`.

Каждый вызов проходит через API, поэтому ассистент может ровно то же, что его токен: те же модули, то же чтение или запись, та же проверка полей, что в форме админки. Дайте ассистенту отдельный токен — только с нужным и со сроком действия.

Claude Code:

```bash
claude mcp add --transport http atrium https://example.com/mcp --header "Authorization: Bearer <token>"
```

Другим клиентам в настройках MCP нужно то же самое: адрес `https://example.com/mcp` и заголовок `Authorization: Bearer <token>`.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `ATRIUM_MCP_ENABLED` | `true` | MCP-сервер |
| `mcp.path` | `mcp` | Его адрес |

## Адреса на сайте, sitemap и robots.txt

`public_urls` говорит, у каких модулей есть страницы на сайте и по какому адресу; тогда поле символьного кода показывает адрес страницы, а API отдаёт его в `public_url`. См. комментарий в `config/atrium.php` и [Свой модуль](modules.ru.md#страницы-на-сайте).

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `ATRIUM_ROBOTS` | `true` | Отвечать на `/robots.txt` каждого сайта текстом из админки (Сайты → robots.txt). Не на боевом сервере всегда `Disallow: /`. Пока включено, файла `public/robots.txt` быть не должно |
| `ATRIUM_SITEMAP` | `true` | `/sitemap.xml` каждого сайта на всех его языках |
| `sitemap.paths` | `['/']` | Адреса, которые не записи модулей |
| `ATRIUM_COUNTERS_CONSENT` | `false` | Запускать Google Tag и Яндекс Метрику только после того, как баннер о cookie вызовет `window.atriumConsent()` |
| `YANDEX_MAPS_API_KEY`, `GOOGLE_MAPS_API_KEY` | | Ключи для полей с картой |
