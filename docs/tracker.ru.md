# Трекер

[English](tracker.md) · [Русский](tracker.ru.md)

`alveby/atrium-tracker` ведёт работу команды в админке: проекты, задачи в них, комментарии, историю изменений и письмо тому, кому задачу поручили. Это маленький Jira. Им пользуются администраторы и только они: что кому видно и можно, решают их роли и права, на сайт из этого ничего не попадает.

## Установка

```bash
composer require alveby/atrium-tracker
php artisan atrium:module:install alveby/atrium-tracker
```

В меню появятся три раздела в группе **Трекер**: **Проекты**, **Задачи** и **Комментарии к задачам**. Для писем нужна рабочая почта (`MAIL_*` в `.env`); без неё трекер работает, но писем не шлёт.

## Проекты

У проекта есть название, **ключ**, описание, руководитель и участники.

- Ключ — от двух до десяти заглавных латинских букв или цифр, первая буква (`SHOP`, `WEB2`), уникальный. По нему нумеруются задачи: `SHOP-1`, `SHOP-2` … Номер не повторяется, даже когда задачу удалили.
- **Участники** — администраторы, которые работают в проекте. Если они указаны, задачу можно поручить только им и руководителю; если нет — любому активному администратору.
- В **архивный** проект новые задачи не попадают, и в выборе проекта на форме задачи его нет; задачи остаются.

## Задачи

| Поле | Что значит |
|---|---|
| Проект | Где живёт задача. Архивный выбрать нельзя |
| Тип | Задача, История, Ошибка или Эпик |
| Название | До 255 символов |
| Описание | Текст, HTML или визуальный редактор |
| Статус | Один из [статусов](#статусы) |
| Приоритет | Самый низкий, Низкий, Средний, Высокий, Самый высокий: стрелка и слово, не только цвет |
| Исполнитель | Активный администратор |
| Родительская задача | Подзадача задачи или задача эпика, в том же проекте |
| Метки | Любые слова, до 20 |
| Срок | Задача после него и не завершённая помечается как **просроченная** |
| Оценка | Часы, до двух знаков после запятой |
| Вложения | Картинки, PDF, текст, CSV, zip и файлы Office, до 20 штук по 20 МБ |

Что проверяет форма: у эпика нет родителя; родитель из того же проекта; задача не может стать дочерней самой себе или одной из своих подзадач. Автор — администратор, создавший задачу, подставляется сам. Новая задача получает первый статус, а момент, когда задача дошла до статуса «готово», запоминается как время завершения.

## Комментарии и история

Вкладка **Комментарии и история** показывает сверху вниз, от новых к старым, что сказали и что произошло: комментарии и строку на каждую смену статуса, исполнителя и приоритета — кто и когда. Чтобы написать комментарий, заполните **Новый комментарий** и сохраните задачу. Больше нигде в панели комментарии не добавляются и не правятся, чтобы переписка оставалась такой, какой была.

**Комментарии к задачам** в меню — те же комментарии списком по всем задачам, только для чтения.

## Статусы

Встроенные — **К выполнению**, **В работе**, **На проверке** и **Готово**; последний закрывает задачу. Свои перечисляются в [настройках](#настройки) по порядку: первый получает новая задача, последний закрывает. Если переименовать статус, у задач он остаётся прежним словом, пока их не сохранят заново, поэтому сначала поменяйте задачи.

## Мои задачи и фильтры

Кнопка **Мои задачи** над списком показывает то, что поручено вам и не завершено (`/admin/tracker_tasks?mine=1`). Над списком: проект, статус, исполнитель, тип, метка, **Просроченные** и **Мои**.

## Почта

Письмо на языке самого администратора уходит исполнителю, когда:

- ему поручили задачу (новую или переданную позже);
- у его задачи сменился статус.

Тому, кто сам вносит изменение, о нём не пишут; неактивному администратору тоже. Письмо уходит только после того, как изменение сохранено окончательно. Текст простой, со ссылкой на задачу. Каждый вид можно отключить в настройках.

## Настройки

Экран настроек модуля (`/admin/modules/tracker/settings`):

| Настройка | По умолчанию |
|---|---|
| Статусы (до 15) | пусто: встроенные четыре |
| Письмо при назначении | включено |
| Письмо при смене статуса | включено |

## Права

У каждого из трёх разделов обычные права в форме роли: просмотр, создание, изменение, удаление. Роль, которой разрешён только просмотр, видит списки и задачи и ничего не меняет; **Комментарии к задачам** только для чтения у всех.

## Хуки

Два события для других модулей и сайта:

```php
use Atrium\Admin\Facades\Hook;

Hook::on('atrium.tracker.task.status_changed', function (Task $task, string $from, string $to): void {
    // ...
});

Hook::on('atrium.tracker.task.assigned', function (Task $task, int $assigneeId): void {
    // ...
});
```

## Демо

`php artisan atrium:install --demo` или `atrium:module:install alveby/atrium-tracker --demo` создаёт два проекта (интернет-магазин и сайт компании) и десять задач во всех четырёх статусах: эпик, подзадачи, просроченные, метки и по комментарию. Если в трекере уже есть проект, ничего не делает; писем не шлёт.
