# ИИ-помощник для текстов

[English](ai.md) · [Русский](ai.ru.md)

Модуль `alveby/atrium-ai` добавляет под текстовыми полями админки ссылку **Сгенерировать**. Он пишет описания, анонсы, SEO-теги и alt для картинок, а ещё переводит поле на другие языки сайта. Текст появляется в окне: редактор читает его и решает, брать или нет. Пока не нажата **Сохранить**, ничего не сохраняется.

Модуль работает на официальном [Laravel AI SDK](https://laravel.com/docs/13.x/ai-sdk), так что подойдёт любой провайдер, которого знает SDK. Здесь он настраивается на бесплатном. Полный справочник — в [packages/ai/README.md](../packages/ai/README.md).

## 1. Выбрать провайдера

| Провайдер | Цена | Ключ | Ваши тексты |
|---|---|---|---|
| Google Gemini | Бесплатный тариф с дневными лимитами | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | **На бесплатном тарифе Google вправе использовать запросы и ответы для улучшения своих продуктов, и их могут читать люди** |
| Groq | Бесплатный тариф с лимитами в минуту и в день | [console.groq.com/keys](https://console.groq.com/keys) | См. условия Groq |
| OpenRouter | Модели с `:free` в конце бесплатны, с лимитами | [openrouter.ai/keys](https://openrouter.ai/keys) | Зависит от того, кто держит модель |
| Ollama | Бесплатно, на вашем сервере | не нужен | Не покидают ваш сервер |
| OpenAI, Anthropic, Mistral и другие | Платно | в их кабинетах | Платные API по умолчанию не учатся на ваших данных |

По умолчанию стоит Gemini: бесплатный, быстрый, понимает картинки (для alt) и хорошо пишет на многих языках. **Если в записях есть что-то закрытое** (цены, которые ещё не объявлены, имена людей, внутренние заметки), берите Ollama или платный ключ.

Можно указать несколько. Если первый ответит «слишком много запросов» или не уложится во время, спросят следующего.

## 2. Поставить модуль и вписать ключ

```bash
composer require alveby/atrium-ai
php artisan atrium:module:install alveby/atrium-ai
```

Ключ — в `.env` на сервере. Atrium его нигде не показывает и больше нигде не хранит:

```dotenv
GEMINI_API_KEY=...
```

Два бесплатных провайдера лучше одного: второй ответит, когда первый упрётся в лимит.

```dotenv
GEMINI_API_KEY=...
GROQ_API_KEY=...
```

Проверить:

```bash
php artisan atrium:ai:status
```

В таблице — каждый вид работы (текст, картинки, эмбеддинги), его провайдеры по порядку и есть ли у каждого ключ. Откройте форму в админке: под текстовыми полями появилось **Сгенерировать**.

### Вместо этого Ollama

Поставьте [Ollama](https://ollama.com) на сервер или рядом и скачайте модель, например `ollama pull llama3.2` для текста и `ollama pull gemma3:4b` для картинок. Потом:

```dotenv
ATRIUM_AI_TEXT=ollama:llama3.2
ATRIUM_AI_VISION=ollama:gemma3:4b
OLLAMA_URL=http://127.0.0.1:11434
```

Маленькая модель на сервере без видеокарты отвечает десятки секунд. Это не страшно: форма её не ждёт.

### Платный провайдер

Его ключ и его имя в цепочке:

```dotenv
OPENAI_API_KEY=...
ATRIUM_AI_TEXT=openai,gemini
ATRIUM_AI_VISION=openai
```

`провайдер:модель` выбирает модель, иначе берётся модель SDK по умолчанию для этого провайдера. Все провайдеры и имена их ключей — в `config/ai.php` из SDK.

## 3. Очередь, если сайт нагружен

Большинству сайтов ничего делать не надо. **Сгенерировать** отвечает сразу, а провайдера PHP спрашивает в том же процессе сразу после этого ответа, пока окно ждёт результат. Обработчик очереди не нужен, как и всему остальному Atrium.

Если генерируют много редакторов одновременно или медленная локальная модель держит процессы PHP, вынесите работу в очередь с обработчиком:

```dotenv
ATRIUM_AI_QUEUE_CONNECTION=database
ATRIUM_AI_QUEUE=ai
```

```bash
php artisan queue:work --queue=ai,default
```

Обработчик держите запущенным через Supervisor или systemd.

## 4. Выбрать поля

У SEO-полей (заголовок, описание, ключевые слова, alt картинок) кнопки уже есть. В своих модулях поле включает их через `->ai()`:

```php
ContentField::make('detail_text')->label('Description')->ai(),
ContentField::make('preview_text')->label('Preview')->ai('preview', from: 'detail_text'),
TextField::make('picture_alt')->label('Picture alt')->ai('alt', from: 'picture'),
```

Без аргументов поле пишется по всему остальному в форме. Другие задачи — `preview`, `seo_title`, `seo_description`, `seo_keywords` и `alt`; `from` называет поля, из которых брать текст.

У переводимого поля, когда у сайта больше одного языка контента, есть ещё **Перевести**: оно переводит язык, который сейчас редактируется, на остальные. Подходит любой язык Atrium, а где важна письменность, модели её называют (узбекский латиницей, казахский и белорусский кириллицей).

Запросы к ИИ — это Blade-шаблоны. Чтобы поменять тон или добавить правила («всегда упоминай бесплатную доставку»):

```bash
php artisan vendor:publish --tag=atrium-ai-prompts
```

и правьте файлы в `resources/views/vendor/atrium-ai/prompts`.

## 5. Спросить помощника

Когда у текстового провайдера есть ключ, на каждой странице админки в правом нижнем углу появляется арка Atrium. Нажмите на неё и спросите на своём языке:

- «Как добавить пункт меню?» Ответ он ищет в этих руководствах.
- «Сколько у нас товаров?», «Найди новость про распродажу». Он читает записи и даёт на них ссылки.

Он отвечает на языке, на котором вы спросили, каким бы ни был язык админки. Он читает только те модули, которые вам можно открывать, и ничего не меняет. Если установлен модуль мониторинга, помощник может сказать и о скорости сайта. Разговор живёт, пока открыта вкладка; **Новый разговор** начинает заново.

По арке видно, чем занят помощник. Пока думает, поднимает брови. Когда пришёл ответ, улыбается. Если ответить не смог, грустит. Ищет по записям с лупой, а руководства читает в очках. Когда пишется текст поля, берёт карандаш, а под Новый год надевает колпак. Изредка зевает, оглядывается или подпрыгивает. Сам он никогда не открывается и ничего не говорит. Если в системе включено «уменьшить движение», арка стоит на месте и меняется только лицо. Программа чтения с экрана сообщает, чем помощник занят. **Модули → ИИ → Весёлый помощник** всё это выключает, и остаётся спокойная арка.

Вопрос и то, что помощник прочитал (разделы руководств, записи), уходят провайдеру. Если на сайте есть закрытые данные, возьмите Ollama или платный ключ либо выключите помощника:

```dotenv
ATRIUM_AI_HELP=false
```

## На публичной демонстрации

При `ATRIUM_DEMO=true` ([demo.ru.md](demo.ru.md)) все посетители — один администратор. Тогда модуль даёт всему сайту `ATRIUM_AI_DEMO_DAILY_LIMIT` обращений в день (по умолчанию 40, `0` — без потолка), чтобы один посетитель не выбрал бесплатную квоту провайдера; когда она кончилась, окно говорит об этом, а API отвечает 429. Окно и помощник также напоминают, что демо публичное и персональные данные вводить нельзя. Подробности: [packages/ai/README.md](../packages/ai/README.md#public-demo).

## Когда он не отвечает

| Окно пишет | Почему | Что делать |
|---|---|---|
| Все провайдеры ИИ заняты или исчерпали бесплатный лимит | Каждый провайдер в цепочке ответил лимитом или не уложился во время | Подождать минуту или добавить второго провайдера |
| Сначала заполните название или текст | Форме не из чего писать | Заполнить название или текст, из которого писать |
| Дневной лимит ИИ в демо исчерпан | Публичное демо разрешает всем посетителям вместе фиксированное число обращений в день | Попробовать завтра или поднять `ATRIUM_AI_DEMO_DAILY_LIMIT` |
| Сначала загрузите картинку | Для alt нужна картинка, сохранённая на этом сайте | Загрузить её: картинки с чужих сайтов не скачиваются |
| Провайдер ИИ не ответил | Любая другая ошибка: неверный ключ, несуществующая модель | Подробности — в `storage/logs/laravel.log` |

Кнопок нет совсем: `php artisan atrium:ai:status` покажет, есть ли у провайдера ключ, а `ATRIUM_AI_ENABLED` не должен быть `false`.

Каждый вызов пишется в таблицу `ai_usage` без текстов: задача, провайдер, модель, токены, время. `php artisan atrium:ai:status --days=7` складывает их — видно, когда бесплатный лимит близко.
