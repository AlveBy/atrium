- Roles on one site. With more than one site, a superadmin gives an administrator roles on single sites as well, under **Roles on one site** on the administrator's form (`admin_role_site_user`). Such a role counts only while its site is the one the panel works with, on top of the roles on every site, so the same administrator edits one site and only reads another; the menu, the buttons and what is allowed change with the site picked in the header. An API call gets a site's roles when it names the site with `?site=`. `$user->hasAdminPermission()` answers for the site of the request, so modules need no change ([docs/modules.md](docs/modules.md#roles-on-one-site)).
