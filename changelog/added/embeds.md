- Embeds: an editor puts a form into any text. The visual editor's toolbar has a **+** button, "Insert form or block": choose a type, find the item by a part of its name and it stands in the text as a labelled chip that moves and deletes like a picture, at the caret. It is stored as `<div data-atrium-embed="form" data-id="3"></div>`, which the editor now keeps instead of dropping, and which the HTML mode, the API and the importers pass through as any text. The site swaps each placeholder for the current item on every request through the new `@embeds` Blade directive (`Embeds::render()` in PHP), which the theme's templates use for every text, so a cached text never shows a stale form; a form that is switched off or deleted, a type of a module that is not installed or an embed that throws leaves nothing and the page is drawn (the error goes to the log). A module registers a type with `Hook::register(Embeds::REGISTRY, 'key', new MyEmbed)`: implement `Atrium\Admin\Embeds\Embed`, or extend `ModelEmbed` for a record of a model and write only the model and how one record looks on the site. The picker is `GET /admin/embeds/{type}`, with the module's `view` permission; the first type is **Form** in `alveby/atrium-forms`. Labels in 15 languages. See [docs/embeds.md](docs/embeds.md).
