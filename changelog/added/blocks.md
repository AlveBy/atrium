- `alveby/atrium-blocks`: reusable blocks. A phone number, an address or a banner text is written once in **Blocks** (name, code, content per language, active, per site) and shown wherever it is put: inside any text with the editor's **+** button (**Block**, found by name; the text holds the block's id, so a new code breaks nothing), in a template with `@block('phone')` or `atrium_block('phone')`. A block may hold a form or another block, and one that holds itself is cut where it would repeat. A block is read once per site, language and code and cached for an hour; saving or deleting any block refreshes it on every cache store. Switched off, missing or not installed: an empty place. Labels in 15 languages. See [docs/blocks.md](docs/blocks.md).
