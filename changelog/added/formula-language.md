- **Formulas**, the first part of Atrium's own language, as the new package `alveby/atrium-language` ([docs/language.md](docs/language.md)): written as in a spreadsheet with English or Russian function names (`SUM` / `СУММ`, `IF` / `ЕСЛИ`, `ROUND` / `ОКРУГЛ`), fields called by their names (spaces and Cyrillic included), `;` or `,` between arguments, exact decimals and dates. They are checked before running, with errors that name the line, the column and the field in 15 languages; run by an interpreter with limits on steps, time, memory and recursion; and can show which values a result was made of. They are stored as a versioned tree (JSON), and modules add their own functions to the registry `atrium.language.functions`. For developers for now: `Formula::parse()`, `check()`, `evaluate()`; no screen in the admin yet.
