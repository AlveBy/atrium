- Pages made of blocks: a page can be put together from sections, columns and blocks instead of written as one text. Built in: text (with embeds), picture, gallery, button, map, and with their modules a reusable block, a form and a menu. A minimal editor on the page form adds, orders and deletes them; history and restoring work for blocks too. A module adds its own block type in a few lines. Run `php artisan migrate`; pages without blocks look as before ([guide](docs/site-builder.md)).
