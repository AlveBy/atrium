- Dashboard tiles are registered by key in `atrium.ui.gadgets`, the panel's own (`site-speed`, `performance`, `recent`) and the errors and monitoring modules' (`errors`, `monitoring`) the same way as a package's, and a package can draw its tile with a Blade view by extending `Atrium\Admin\Dashboard\HtmlGadget`, without building any Vue ([docs/modules.md](docs/modules.md#dashboard-tiles)). `atrium.dashboard.gadgets` stays the layout and takes keys as well as class names; a registered tile it does not name now comes after the ones it does, so switch one off with `['gadget' => 'errors', 'enabled' => false]`.
